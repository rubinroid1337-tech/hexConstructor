# hexConstructor — Документация симулятора логических схем

**hexConstructor** — визуальный симулятор цифровых логических схем на C++ и Raylib. Позволяет проектировать комбинаторные и последовательностные схемы в реальном времени, сохранять их в JSON и тестировать работу сигналов.

---

## 1. Базовые компоненты

### Ввод и вывод
* **Switch (Переключатель)** — источник сигнала (`0` или `1`). Переключается одиночным кликом ЛКМ (без сдвига мыши).
* **LED (Лампочка)** — индикатор выходного сигнала. Загорается красным при подаче логической единицы (`1`).

### Логические вентили

| Вентиль | Входы | Логика работы | Описание |
| :--- | :---: | :--- | :--- |
| **AND** | 2 | `A && B` | Выдаёт `1`, только если оба входа равны `1`. |
| **OR** | 2 | `A \|\| B` | Выдаёт `1`, если хотя бы один вход равен `1`. |
| **XOR** | 2 | `A != B` | Исключающее ИЛИ: выдаёт `1`, если входы не равны. |
| **NOT** | 1 | `!A` | Инвертор: меняет `0` на `1` и `1` на `0`. |

## 2. Управление и горячие клавиши (Hotkeys)

### Создание элементов (в позицию курсора)

| Клавиша | Действие |
| :--- | :--- |
| **`1`** | Добавить переключатель (**Switch**) |
| **`2`** | Добавить индикатор (**LED**) |
| **`Q`** | Добавить вентиль **AND** |
| **`W`** | Добавить вентиль **OR** |
| **`E`** | Добавить вентиль **XOR** |
| **`R`** | Добавить вентиль **NOT** |

### Провода и взаимодействие

| Действие / Клавиша | Описание |
| :--- | :--- |
| **Клик ЛКМ по Switch** | Переключить состояние (`ON` / `OFF`) |
| **`Shift` + ЛКМ по пину** | Начать/завершить соединение проводом (выход → вход) |
| **`X`** | Удалить выделенные элементы или провод под курсором |

### Навигация и редактирование

| Действие / Клавиша | Описание |
| :--- | :--- |
| **`Space` + ЛКМ (тянуть)** | Перемещение камеры по рабочей области (Pan) |
| **Колесо мыши** | Приближение и отдаление в точку под курсором (Zoom) |
| **ЛКМ (тянуть по пустому месту)** | Выделение группы элементов рамкой |
| **ЛКМ (тянуть элемент)** | Перемещение элемента или выделенной группы |
| **`Ctrl + C`** | Копировать выделенную область в буфер обмена |
| **`Ctrl + V`** | Вставить скопированную схему в позицию курсора |
| **`Ctrl + Z`** | Отменить последнее действие (Undo) |
| **`Ctrl + Y` / `Ctrl + Shift + Z`** | Повторить отменённое действие (Redo) |
| **`Esc`** | Отменить протяжку провода / снять выделение / выход |
| **`F11`** | Переключить полноэкранный режим |

---

## 3. Как работает симуляция и сохранение

* **Цикл расчёта (`Circuit::tick`):** На каждом кадре сбрасываются входы вентилей и индикаторов, передаются значения по всем проводам от выходов к входам, после чего каждый вентиль вычисляет новое выходное состояние.
* **Формат файлов:** Схемы сериализуются в JSON (состояния вентилей, переключателей, проводов и их координаты на холсте) и автоматически сохраняются в `save.json`.
